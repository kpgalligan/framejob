# 4.3b Inspector — the Media, Document and Assistant tabs

The tab strip and the Clip tab are §4.3a.

**Media tab** — a 38 pt action row (Add Media…, its ⇧⌘I hint, a right-aligned
item count), a 60 pt **find band**, the list, then a 40 pt footer holding
Consolidate… and a line saying what it does.

- The find band is two lines: a search field across the top (name contains,
  case- and diacritic-insensitive, as you type), then a Sort popup — **Import
  Order** · Name · Duration · Kind — and an "Unused only" switch. It is two
  lines rather than one because the three controls measure 319 pt against the
  284 the panel leaves at its default width. The row spells "Import Order"
  and not "Added" because nothing records when a file arrived: `Media` has no
  timestamp, and what exists is the array's own insertion order, which is
  also ascending id order for any project built by ops. The action row's
  count becomes "N of M items" while anything is narrowing.
- None of the three is persisted, and the band never rebuilds the pane: the
  rows it already built are hidden and re-ordered in place, because
  `InspectorPaneView.rebuild()` destroys the field editor and the caret with
  it. A search is an act of finding, not a preference.

- Every imported file as a 52 pt row: a 34 × 38 pt thumbnail, the name at
  12 pt, a mono 10 pt meta line of duration, dimensions and fps, an
  audio badge, a "missing" badge. Add Media… (⇧⌘I); drag files from the
  Finder onto the panel, the canvas, or the timeline. A WebM or Matroska
  file's row names the ORIGINAL (`talk.webm`), not its `.mov` copy, and its
  tooltip says where the copy lives on a line above the drag hint —
  "`<original path>` — copied into Reelcut's Rewrapped folder.", or "… —
  copied into this project's package." after Consolidate (§11 #228-O). No
  badge.
- Drag from the list to a timeline track (drops at the cursor) or onto
  the canvas (appends on a new top track at the playhead).
- Right-click: Reveal in Finder (a copy's original, or the copy when the
  original is gone), **Reveal in Timeline**, Relink…, Remove
  (refuses while in use and offers "Remove and delete its clips"). Reveal in
  Timeline selects the clips whose source is that file and scrolls the
  timeline to the earliest of them; it is disabled for a file whose only
  users are INSIDE a nest, because the selection holds top-level clip ids
  alone. "Is this file used" is one question with one answer
  (`MediaUsage.swift`), and it walks the nests the way the core's
  `every_clip()` does — Remove and the `remove_media` tool ask it too.
- Files are referenced (path + `URL.bookmarkData()`; the app is not
  sandboxed, so no security scope), never copied. File ▸ Consolidate
  Media… — and the pane's own Consolidate… button — copies them into the
  package and relinks the project at the copies, with a progress sheet and
  a Cancel; §5.6 has the rules it follows.
- File ▸ Import Captions… reads a SubRip (`.srt`) file and lays it out as
  text clips in the Caption preset on a track of their own, which is what
  makes burn-in on export free: a caption is an ordinary text clip, so it
  retimes, restyles and renders like one. Malformed entries are reported
  with their line numbers rather than skipped in silence.
- File ▸ Generate Captions… (road map 2's phase 4, a second engine in road
  map 6's C1) makes the same clips out of SPEECH: a sheet picks the ENGINE
  — **On this Mac**, Apple's own recogniser, or **AssemblyAI**, in the
  cloud — the language and the scope (the selection, the in/out range, or
  everything with sound), and the same card becomes its own progress bar
  while it runs. The cloud engine sends audio off the machine, so the sheet
  says which files it would upload, how long they are and what they would
  cost at the published rate BEFORE the button does anything; the key is a
  `0600` file behind Reelcut ▸ Settings… (⌘,), the words come back into
  `cache/transcripts/<media>.json` in the package and are re-used by the
  next run, and the copy at the far end is deleted as soon as it has been
  read. Road map 6 §5 is its specification and §11's R6 rows are its
  decisions.

  The rest of this bullet is the ON THIS MAC engine's, unchanged. It
  transcribes each clip's own source window, extracted to a
  temporary audio file — never the media file as it sits, and never the
  whole of a long recording for the sake of a short clip. Since road map
  8's W2 (§11 W-8) the engine is `SpeechTranscriber`: no grant is asked
  and there is no length ceiling. The Language popup lists every supported
  locale, one whose model is not on this Mac marked "— not installed", and
  choosing one shows a Download row — the one place a model is installed;
  Generate runs only for an installed language. Cues are at most two lines
  of 42 characters, at most six seconds, with at least a frame between
  them.

  Since road map 8's W4a a run can make WORD CAPTIONS instead, in one of
  five styles — Highlight, Pill, Karaoke, Build and One Word (road map 8
  §5h, `CaptionStyle.swift`) — besides Subtitles, which is the cue path
  above, unchanged. A word caption is a PAGE: an ordinary text clip filled
  to the width it MEASURES in its style on this canvas (at most 0.86 of the
  canvas width), never to a word count, on one line (Karaoke: two), each
  word's timing carried in `text.words` so the word being said is drawn as
  the style says (§11 W-1, W-7). A lone word too wide for the budget
  shrinks, then wraps. A run may REPLACE the caption tracks it would have
  made over the same clips in the same undo step, which is how a track is
  restyled (§11 W-10). The sheet's **Style** popup (road map 8's W4b)
  lists Subtitles and then the five, opens on the style last chosen, and
  shows a preview under it: the first page generation would make — of the
  first clip's cached transcript when there is one, else "This is how it
  looks" — drawn by the renderer itself at this canvas's size, two frames
  for a word style (the first word active, then the second). A **Replace
  existing captions** checkbox is live only for a word style over a track
  the command itself would replace, and lists those tracks by name with
  their caption counts before Generate; the sheet commits exactly what
  `transcribe`'s `style`, `replace`, `slide`, `fill` and `dim` (§7.9)
  commit.

  Since issue batch B86 (§11 W-15) three checkboxes sit under the Style
  popup, one per line, each off by default and remembered when clicked:
  **Slide the pill** (the pill slides from word to word instead of
  jumping; live with Pill), **Fill words as spoken** (the word being said
  fills left to right; live with Highlight, Karaoke and Build) and **Dim
  in pauses** (the page fades to half in a pause of a quarter second or
  more; live with every word style). A box that does not apply to the
  chosen style is greyed, keeps its tick and does nothing. With On this
  Mac selected and a word style chosen, a note under Dim says "On-device
  words rarely carry a pause; this shows mostly with AssemblyAI.", and the
  card is about two lines taller while it shows. The preview's two frames
  show a ticked fill half done and a ticked pill half-way through its
  slide; the dim is not previewed.
- File ▸ Export Captions… writes one track of text clips back out as
  SubRip (`.srt`) or WebVTT (`.vtt`) — the clips' own times and words, so
  a caption retimed by dragging exports where it was dragged to. The track
  is never guessed: a candidate is a track whose clips are ALL text, and
  with none or with more than one the command names the candidates and
  offers a popup instead of choosing. A cue written out and read back in
  lands on the TICK it left, at every ordinary frame rate: `format_timecode`
  rounds to the nearest millisecond, which is at most 300 ticks, and half a
  frame is 10,000 ticks even at 30 fps, so the snap on the way back in can
  only find the frame the cue came from. What is not exact is the FILE.
  Import snaps every cue to the frame grid, so a source whose times are off
  that grid comes back written onto it — at 30 fps `00:00:04,120` returns as
  `00:00:04,133` — and byte identity with the file you imported needs cue
  times already on the grid AND a frame that is a whole number of
  milliseconds, which is 25 or 50 fps.

**Document tab** — a summary group first (Resolution, Frame rate, Duration,
Tracks, Background as read-outs on an 86 pt label column), then the editable
groups below it.

- Canvas size: presets (1080p, 4K, 720p, 1080×1920 vertical, 1080×1080
  square, 2560×1440, source size) or custom; a "resize clips
  proportionally" toggle when changing.
- Frame rate: 24, 25, 30, 50, 60, 23.976, 29.97, or "match first clip".
- Background color. Duration read-out. Timecode format (frames vs ms).
- "Fit new clips to canvas" (default on): a dropped clip larger than the
  canvas gets Fit scale.
- Markers list: rename, jump, delete, chapter toggle. Chapter markers
  export as a chapter track (M2, `AVAssetWriter` path).

**Assistant tab** (§11 AI-4; road map 12 A2) — a conversation with the
built-in assistant, which edits this window's project through the agent's
tools (AI-2, AI-5). Top to bottom: a context strip — "CONTEXT", the figures
("Nothing reported yet", "N of L tokens · P%" or "N tokens (window size
unknown)"; where that does not fit, "N / L · P%" and then "P%", or "N
tokens"; its tooltip always the full figure) and a square 3 pt bar filled
to the used share, coral past 80% — with Clear (↺) at its right end, which
ends the conversation and empties the transcript; under it the Spend row
(road map 13 P4, §11 P-4, P-7) — "SPEND" and what the conversation has cost
since its last Clear or ended conversation, as Reelcut estimates it at
LiteLLM prices: "Nothing yet", "$0.0018 · Reelcut's estimate", "at least
$%.4f · Reelcut's estimate" when a response could not be priced or was cut
short by Stop or an error (§11 P-8), or "unknown · Reelcut's estimate",
never $0; where that does not fit, "≥" for "at least" and "<" for "under"
(§11 P-8); its tooltip says the Anthropic Console shows what the account was
billed; the transcript, one selectable text scrolled to the newest line, so
a selection crosses entries and copies as plain text, entries separated by
a line break (AI-17): the person's
messages in semibold, the streamed reply, progress notes in faint text, a
mono meta line per tool call (`name (k: v, …)`, `project` left out, 70
characters), per failed result (`failed: …`), per answer (`Allowed: …`,
`Declined: …`, `Declined (stop): …`) and per compaction, and errors in coral;
the ask-first row while a question waits — "The assistant asks first:", the
question's sentence (`export writes <path>`, `export REPLACES <path>` when a
file is there), Allow and Deny; and the composer, "Ask about or edit this
project…", which grows from one line to five and then scrolls, with a 64 pt
accent Send that reads Stop while a turn runs or a
question waits. Return in the composer sends only while idle and beeps
otherwise; ⇧, ⌘, ⌥ or ⌃Return inserts a new line (AI-17, K-2's rule), and
Tab and ⇧Tab move focus; Allow and Deny take a click and no key, so Return never answers a
question. With no key (the store, then `ANTHROPIC_API_KEY`, AI-8) the
composer gives way to "Add your Anthropic API key in Settings to use the
assistant." and Open Settings…. The tab holds no conversation: the
transcript and the session are the window's, so a later floating window is
a second host for the same views (AI-4). View ▸ Assistant ⌃⌘A shows the
inspector, picks the tab and focuses the composer.
