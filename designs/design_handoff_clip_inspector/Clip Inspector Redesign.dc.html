1Clip inspector: three sub-tab structures, plus the shared parts

All three directions split Clip into sub-tabs so picture, sound and clip timing stop sharing one list. The Picture tab of a video clip drops from 21 sections to 10. They differ in where actions live and how you enter one.

All three share the same parts: an "editing action N" mode you enter by selecting an action, row marks that show what the action changes, end-value fields for P8, and one Reset rule. Those are studied below the directions (1d–1j).

Assumptions: dark only, video+audio and text clips, and orchid as a placeholder action colour until you pick one from 1d–1f. Example clip "Intro demo", 5 s, with two actions and the playhead at 03:06, inside action 2.

Structure
1aFour sub-tabs: Picture · Sound · Time · Animate
The by-the-book split. Actions get their own tab with the Motion presets (clearly marked as not actions). Selecting an action puts a mode bar above the sub-tabs, which stays while you move to Picture or Sound to edit its end values. Text clips swap Sound for a Text tab.

1bPinned action lane + Picture · Sound · Clip
A mini timeline of the selected clip sits above the sub-tabs on every tab. It shows each action as a band with the playhead, like the timeline itself does. 1cEdit target first: Clip · 1 · 2 · +, and an action shows only what it changes
The row at the top picks what you are editing: the clip or one of its actions, in time order. The clip gets the usual Picture · Sound · Clip tabs. An action gets a short list of its end values, grouped by section, plus "+ Property" to animate something else. This is the densest fix, because an action with four changes is four rows.

1gFields show the end value; the coral tick shows the playhead valuerecommended
at rest · playhead 03:06
after typing 60% into Opacity
What you type is what the field keeps. The knob and the field both sit at the end value, and the orchid segment on the rail runs from the start value to the end value. The coral tick is the value at the playhead, drawn in the playhead's colour, and it moves with scrubbing. Fields without a slider show the playhead value as a coral readout. Dragging the knob sets the end value, so the knob stays under the pointer.
1hFields show the playhead value, with the end value as a target
at rest · playhead 03:06
Opacity focused: field swaps to the end value
At rest the field matches the preview: dim playhead value, then the end value after the arrow. The knob sits at the playhead value and the outlined block marks the end. On focus the field swaps to the end value and says so. It is more honest about the preview but costs width (92 px fields), and a click still changes what the field reads.

Stronger fill, the label, and white grips on both ends. Drag the middle to move, an end to retime. Click to select.

Solid fill with the curve drawn inside, a wash down the body of the clip, and the span shaded on the ruler. The playhead jumps to the action's end.

A dashed ghost stays at the old start and a timecode tag shows the new start and the offset. It snaps to the playhead and neighbours, and stops at them rather than overlapping.
Marking and Reset model (shared by all directions)
1jRow marks, header badges, Reset and notes
◆Keyed in this action. Numbers and colours glide to the end value. Switches, text and menus change at the end, and say "at end". ◇Changed by another action. Held here. Editing it adds it to this action. With no action selected, it means some action changes this row. ○Follows a keyed value. Read-only readouts that move because something else is keyed: Gain follows Volume, Position follows Pan. ⊘Actions can't animate this. Motion presets, shape properties, pan, compressor, noise reduction, ducking. Edits change the clip even while an action is selected, and the row says "clip" (P7). Value at the playhead. Drawn in the playhead's colour, never editable (P8). ◆2Header and sub-tab badges count the keyed rows inside, so a collapsed section or another tab still shows what the action touches. The summary turns orchid and shows the end value.
RESET (P11)
Reset shows only when a section differs from its default, and always returns it to the default: off, neutral or 100%. Stroke, Shape and Style follow the same rule. With an action selected, the same slot reads Clear. It removes that section's keys from the action, and the values go back to what was held. Each keyed row also has its own remove (the × in 1c, or a context menu elsewhere). Sections with no default (Content, Timing, Transition, Actions) have no Reset slot.
NOTES (P6)
The per-section blue note goes away. One mode bar (or the selected target) says which action you are editing, and the row marks do the rest. Inline notes are kept only for warnings: blend with nothing behind it, and Reveal overridden by word captions. Also: canvas handle drags follow the mode (P9), and unchecking a switch inside an action keys it off rather than removing the key (P10).
