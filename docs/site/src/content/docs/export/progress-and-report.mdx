After you choose **Export…** on the export sheet, Frame Job asks where to save, then writes the file behind a progress sheet. When it's done, the sheet tells you what the sound measured and what went wrong, if anything did.

**Add to Queue** opens the same save panel, then writes the file behind the editor so you can keep working. See [The Export Queue](/export/export-queue/).

## The save panel

The save panel suggests the project's name with the format's extension, such as `Board v1.2.mp4`. Its message says what's being written:

| Format | Message |
| --- | --- |
| A movie | "Export the timeline as a movie." |
| Animated GIF | "Export the timeline as an animated GIF." |
| Animated PNG | "Export the timeline as an animated APNG." |
| Audio only | "Export the timeline's audio." |

Cancelling the save panel writes nothing. The export sheet has already closed by then, and it keeps the choices you made for next time.

## The Exporting sheet

**Exporting** shows a progress bar, a percentage and a status line. The status line moves through these:

| Status line | What's happening |
| --- | --- |
| "Preparing “*name*”…" | Frame Job is getting everything ready, and may be waiting for something the file needs. |
| "Measuring loudness…" | The sound is being [measured](/export/loudness/#how-normalisation-works). Every export with sound does this, whether or not you chose a target. |
| "Writing “*name*”…" | The file is being written. |

The file is written from the timeline as it was when you confirmed it.

### While it says Preparing

Some of what a file holds has to be made first, so the export waits for it:

- The masks of every [Remove Background](/effects/remove-background/#exports) clip in the range, with no time limit.
- Each clip's cursor, from its [cursor file](/recording/cursor-files/).
- The measured loudness of every clip with a gate, leveller or de-esser, for up to five minutes.
- The rendered sound of speed changes, Voice Isolation and voice effects.

GIF and APNG files have no sound, so they don't wait for the last two. You can cancel during any of these waits. [Waiting for what it needs](/export/what-an-export-includes/#waiting-for-what-it-needs) lists which clips each wait covers, and what happens if something can't be made.

## Cancel a running export

Choose **Cancel**. The button greys out, and the status line reads "Stopping…" until the sheet closes and the partly written file is removed.

A file you chose to replace in the save panel stays as it was until the export finishes. Frame Job writes the new file under a hidden name in the same folder and puts it in place of the old one only once it's complete, so cancelling at any point, even while the sheet says "Writing", leaves the old file untouched. The folder needs room for both files while the export runs.

## The finish report

When an export finishes, the status line names the file and says what the sound measured:

> Exported “name.mp4”. Peak −1.0 dBTP · −14.0 LUFS.

[What the loudness line means](/export/loudness/#what-the-loudness-line-means) explains those figures. A file with no sound has no figures. An export with [stems](/export/stems/) counts them after the name: "Exported “Mix.wav” and 3 stems."

**Show in Finder** reveals the file and closes the sheet. **Close** closes the sheet.

## Graphic and cursor warnings

A warning doesn't stop an export. The finish line adds a count, and its tooltip lists each warning.

| Warning | What happened | What the tooltip lists |
| --- | --- | --- |
| "1 graphic warning (hover for details)." | A [graphic](/graphics/what-is-a-graphic/) warned while the file was drawn. | Each warning, with the graphic's name and its frame. |
| "1 cursor warning (hover for details)." | A clip's cursor file couldn't be drawn, so that clip is written without its cursor. | Each one, for example "The cursor of media 3 is not drawn: …" |

The cursor count comes after the graphic count. A finished row in the Export Queue shows the same counts, and its tooltip lists the same warnings.

## Failures

**File ▸ Export…** is greyed out while the timeline is empty. Any other export that can't run says why in a sentence, on the sheet or on its queue row. On the sheet, **Close** dismisses it.

| The sheet says | What to do |
| --- | --- |
| "The export was not started: the graphic …" | A graphic in the range doesn't compile or has no module. Fix it and export again. |
| "The export was stopped at frame … of the graphic …" | A graphic failed at that frame. No file is left. |
| "Clip …'s loudness or speech has not been measured yet…" | A clip's gate, leveller or de-esser needs that measurement. Wait for the **Status** rows in those sections to show the clip's loudness, then export again. |
| "Clip …'s retimed audio could not be rendered: …" | The sound of a speed change couldn't be made. |
| "Clip …'s isolated voice could not be rendered: …" | Voice Isolation couldn't be rendered for that clip. |
| "Clip …'s voice effect could not be rendered: …" | The voice effect couldn't be rendered for that clip. |
| "Clip …'s person masks could not be made: …" or "Clip …'s foreground masks could not be made: …" | A Remove Background clip's masks failed. No frame is written without them. |
| "This Mac cannot export with the “…” preset." | This Mac has no encoder for that format. Choose another format. No file is left. |

Other messages come from macOS or the file being written, and appear as they are.

A failed export removes its partly written file, as a cancel does, and a partly written file is never left at the path you chose. A file you chose to replace in the save panel stays as it was, whenever the export fails.

If the finished file can't be put in place of the old one, for example because the old file is locked in the Finder, the export fails with "“…” could not be replaced with the new export: …. The file there is as it was." and the new file is removed.

If Frame Job quits unexpectedly while it writes, a hidden file whose name starts `.framejob-export-` can be left in that folder. It isn't a finished export, so delete it. The [600-frame limit](/export/gif-and-apng/#the-600-frame-limit) and the [same-shape rule](/export/transparency/#the-same-shape-rule) stop you in the Export sheet, before the save panel.

## Quitting during an export

Frame Job doesn't quit while an **Export…** progress sheet is writing, whether the sheet is on screen or not. If its window is minimised, the window comes back out of the Dock. If Frame Job is hidden, it's shown again and comes to the front. Cancel the export, or let it finish, then quit.

Jobs in the [Export Queue](/export/export-queue/#quit-with-jobs-in-the-queue) ask before they stop.

## With an agent

An agent's `export` puts a job on the Export Queue and returns at once, with no progress sheet. A bad argument, a missing folder, an empty timeline, a graphic that doesn't compile, a range over the 600-frame limit or a size that breaks the same-shape rule comes back from `export` before anything is queued. Failures while writing and the loudness figures come back from `export_status`, and `cancel_export` stops the job.

Warnings arrive in the finished `export_status` as `graphic_warnings` and `cursor_warnings`, and are left out when there are none. The list of graphic warnings stops after 64 distinct ones. See [Export: start, then poll](/mcp/export/).
