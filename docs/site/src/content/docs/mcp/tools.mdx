Frame Job gives an agent 125 tools. This page names every one and links to its full reference, and says how a client can read what each one takes.

## The tool catalog

The 125 tools come in two kinds.

- **69 edit tools.** Each makes one kind of edit to the project, as one undo step. These also take `scope`, which aims the edit inside a [nest](/mcp/nests/) by the nest's id.
- **56 app tools.** These work with files, read things, change what the app is showing, or run a whole command such as `record_screen` or `make_vertical_version`.

Every tool takes `project`, which says which open project it acts on. Leave it out for the front project. See [How tool calls behave](/mcp/tool-calls/).

## How arguments are published

Each tool publishes its arguments as JSON Schema, in the `inputSchema` of `tools/list`. That's where a client reads every argument's name, its kind, its closed list of values, its bounds and which arguments are required. The helper answers `tools/list` even when Frame Job isn't running. See [The helper and the socket](/mcp/helper-and-socket/).

Each tool's description says what it's for and what it returns. An argument that isn't in the schema stops the call before the tool runs, with a message listing what the tool does take: "trim_start does not take at. It takes alone, clip, to, project and scope."

A few arguments read differently from what their kind suggests:

| Argument | What's different |
| --- | --- |
| Every boolean | May also be sent as the string `"true"`, `"1"`, `"false"` or `"0"`. |
| `text` on `add_text_clip`, `shape` on `add_shape_clip` | May be a plain string: the words, or the kind of shape. |
| `kind` on `set_transition`, `region` on `add_zoom_action` | Must be sent even when null, because null means something: no transition, or zoom back out. |
| `rate` on `set_speed` and `add_speed_ramp` | Published as ×0.1 to ×1000. A rate outside that is brought into range, with no error. Zero or less stops the call. |
| `fps` on `set_canvas` | Each of its two numbers must be at least 1. |
| `clips` on every tool but `set_selection`, `groups` on `paste_attributes`, `ranges` on `ripple_delete_ranges` and `copy_pieces` | Can't be empty: the call stops and names the argument. On `set_selection`, an empty `clips` selects nothing. |
| `at` on `split`, `paste`, `freeze_frame` and `add_marker` | Optional. It takes the playhead when left out. |
| `focus` on `switch_layout` | May be null or left out, and the tool then fills it from the camera's cached person masks. |

Four tools need at least one of their optional arguments, because a call that names nothing to change stops with an error: `set_track`, `set_marker`, `set_canvas` and `set_transition_style`.

Frame Job fills a few values itself, from what only it can read, so the tools don't publish them and sending one stops the call: a graphic's `schema`, a relinked file's details, and the faces and turns `reframe_clip` follows.
