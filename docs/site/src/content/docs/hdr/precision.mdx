Frame Job works in 16-bit float, so a gradient from a 10-bit camera file survives grading. There's nothing to turn on. This page says where that depth is kept and where it ends. "Deep" here means more than 8 bits per channel.

<AtAGlance menu="File ▸ Export…" keys="⌘E" tools="export" />

## 16-bit float compositing

Every video source is decoded to 16-bit float, and every frame is composited at 16-bit float. There's no 32-bit float mode. Blends run there too, so a heavy grade keeps its precision. A 10-bit source keeps its detail all the way to a 10-bit or ProRes export.

A 16-bit float frame takes twice the memory of an 8-bit one, so an export needs about twice the memory for its frames.

## 10-bit exports

The format you choose on the [export sheet](/export/export-sheet/) decides how much of that depth reaches the file.

| Format | Depth in the file |
| --- | --- |
| **HEVC 10-bit (MP4)** | 10-bit (Main 10) |
| **AV1 (MP4)**, **AV1 (WebM)** | Always 10-bit |
| **ProRes 422 (MOV)**, **ProRes 4444 (MOV)** | Deep: they take the composited frames as they are, at 10 bits in ProRes 422 and 12 in ProRes 4444. See [ProRes](/export/prores/). |
| **VP9 (WebM)** | 8-bit for an SDR picture, 10-bit for HLG and HDR10 |
| **H.264 (MP4)**, **HEVC (MP4)**, **HEVC with Alpha (MOV)**, **VP9 with Alpha (WebM)** | 8-bit |
| **Animated GIF**, **Animated PNG** | 8-bit |

The sheet's **Bit depth:** row is about sound, not the picture. See [Export bit depth](/export/bit-depth/).

## Deep stills

A still deeper than 8 bits per channel, such as a 16-bit PNG or TIFF or a 10-bit HEIC, is drawn at 16-bit float. An 8-bit still is drawn at 8 bits. It's automatic and there's no setting: add the file with **File ▸ Add Media…** (<kbd>⇧⌘I</kbd>) as usual.

## Saved frames

**File ▸ Save Frame…** (<kbd>⌥⌘E</kbd>) writes a 16-bit PNG or a 10-bit HEIC when the frame shows a deep still or a 10-bit VP9, HEVC or ProRes clip, and always in an HDR (HLG) project. A frame gets the same when the lowest track with video on it holds a 10-bit HEVC or ProRes clip, anywhere along the timeline. A JPEG is always 8-bit. See [Save Frame](/export/save-frame/).

## Reversed clips

A reversed clip plays from a backwards copy rendered at 10 bits, at the source's exact size and with the source's own colour labels, so an HDR or log clip still reads correctly. See [Reverse a clip](/speed/reverse/).

## What stays 8-bit

Text, shapes, captions and screen recordings are 8-bit, and so are thumbnails.

A graphic is drawn at 16 bits per channel in an export that keeps the depth (HEVC 10-bit, AV1, ProRes, and VP9 as HLG or HDR10) and in a frame saved deep, so its gradients keep their levels there. Everywhere else, including the preview and the 8-bit exports, it's drawn at 8 bits with its gradients dithered. A group with a `filter` and the coverage of a luminance `mask` are 8-bit in both. A frame that shows only graphics is saved at 8 bits. In an HDR (HLG) project text, shapes, captions and graphics are still [lifted to HDR reference white](/hdr/dynamic-range/), so they sit with the rest of the picture.
