The Assistant edits the project in its own window. You ask in plain words, it makes the edits one at a time, and each one lands where you can see it. Almost all of them [can be undone](#each-edit-is-an-undo-step). This page goes through what you can ask for, job by job, and where the limits are.

## The same tools as MCP

The Assistant works by calling tools, one for each job. They're the same tools an outside AI agent uses when it connects to Frame Job [over MCP](/mcp/overview/), so anything here is something an agent can do too. There are a few exceptions, listed in [What it won't do](/assistant/what-it-will-not-do/), and some tools that write files [ask you first](/assistant/what-it-will-not-do/#tools-it-asks-about-first).

Four tools are always at hand: reading the project, rendering a frame, undo and redo. It finds every other tool by searching for what it wants to do, so you never need to name one. A tool kept from it outright doesn't turn up in that search at all.

Each job below lists its tools, because those are the names you'll see in the [tool call lines](/assistant/conversation/#tool-call-lines). [All tools](/mcp/tools/) describes each one.

## What you can ask for

Ask in your own words, for example "put a title over the first five seconds". You don't need to know which job a request falls under. See [Chat with the Assistant](/assistant/chat/) for how to send one.

### Projects and navigation

It can open, create and save projects, move the playhead, set the in and out range, change the selection, and enter or leave a nest. It can also make a [new project from a range](/projects/new-project-from-range/) or a [vertical version](/framing/make-vertical-version/).

Saving asks first. Making a new project from a range or a vertical version asks first when it names where to save. A blank new project [doesn't ask](/assistant/what-it-will-not-do/#file-writes-that-do-not-ask), even when it names where to save. Moving the playhead, setting the range and changing the selection aren't edits, so they make no undo step.

A project it opens or creates gets a window of its own, and the Assistant stays with the project it started in.

It can add, move, rename and remove [markers](/timeline/markers/), make one a chapter, and set its colour, which you can't do yourself. It can change the canvas's [size](/projects/canvas-size/), [frame rate](/projects/frame-rate/) and [background](/projects/background-and-timecode/).

## Cut words by asking

You can ask the Assistant to take out filler words, silences or a false start, for example "cut the false start at the beginning of this clip." It cuts each request as one undo step, labelled **Undo Ripple Delete** rather than with the sheet's name.

Its filler search reads only media that already has a cloud transcript made with filler words, and it can't upload audio to make one. In other media the search finds nothing, and it reports which media has no such transcript. To start the paid transcription, press **Transcribe** in the [Remove Filler Words](/cleanup/remove-filler-words/) sheet yourself.

It removes a false start only when you ask, because deciding what counts as one is a judgement of meaning. It reads the words and their times, says which it will cut, then cuts them. The words come from a transcript the file already has or from this Mac's own speech recogniser, so no audio is uploaded. There's no menu command for this.

See [Cut false starts](/cleanup/false-starts/).

## It looks at rendered frames

The Assistant checks its work by rendering a frame of the finished timeline, drawn the way an export draws it. It's told to look before and after a visual edit. It renders at the playhead unless it picks a time, and it's told to keep the image small.

Rendering writes a picture file without asking. By default that's a temporary file.

:::note
The frames it renders go to Anthropic, along with your messages and the project's details. See [Assistant privacy](/assistant/privacy/).
:::

Earlier renders don't survive compaction, so it renders again when it needs to look. See [Long conversations](/assistant/context-and-compaction/).

## Each edit is an undo step

Every edit the Assistant makes is its own undo step on the project, the same as your own, and **Edit ▸ Undo** names it after the edit. A turn isn't grouped, so a turn that made ten edits takes ten undos.

Graphics files are the exception. Writing, restoring, deleting or importing a graphic, and importing a font or picture for one, change files in the project and make no undo step. See [Undo rules](/graphics/agents-and-graphics/#undo-rules).

To take back its last change, press <kbd>⌘Z</kbd> outside the message field. You can also ask the Assistant to undo or redo.

## How it behaves

- **Short replies.** A reply is a sentence or two, and it doesn't repeat what the tool lines already show.
- **Captions only on request.** It writes or restyles a caption only when you ask.
- **Medium effort, thinking on.** The model always runs with these two Anthropic settings, and Frame Job's Settings has no control for them. The faint [working notes](/assistant/conversation/#working-notes) are its thinking updates.

## Only its own window's project

The Assistant acts only on the project in its own window, and each window has its own conversation. A tool call that names another project doesn't run, and the transcript shows a `failed:` line: `The assistant edits its own window's project, …; … is a different project.`

If its project has closed, a tool call fails with "The assistant's project is no longer open."

## Limits

- It works only on the project in its own window, and each window has its own conversation.
- It needs your own Anthropic API key. There's no Frame Job account. See [Set up the Assistant](/assistant/set-up/).
- It can't record, close its window's project, or send audio to the cloud transcriber.
- A tool call that arrives during a drag waits until you release the mouse. See [While you are dragging](/assistant/stop-a-turn/#while-you-are-dragging).
- **Stop** doesn't cancel an export that's already been queued. See [Stop a turn](/assistant/stop-a-turn/).
- With [compaction](/assistant/context-and-compaction/) off, a long conversation eventually fails until you **Clear** it.
- Changing the key or the model ends every window's conversation.
